# Анализ бизнес-процессов
Web-приложение позволяет проводить различные виды анализа бизнес-процессов

Основные возможности: 
1. Моделирование бизнес-процессов.
2. Проведение функционально-стоимостнго анализа.
3. Проведение анализа фрагментарности процесса.
4. Проведение анализа организационной структуры.
5. Проведение анализ причин и следствий
